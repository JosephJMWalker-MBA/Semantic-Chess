# Representation contract v0.1
Standard chess legal moves, including castling, en passant and all four promotion choices, govern play. Queen promotion is described as self-actualization with queen capabilities; other promotion choices likewise preserve identity. Countries are labels, not political actors or allegiances. Their placement is an arbitrary prototype mapping, not geographical adjacency. Coordinates remain canonical internally.

Every starting piece receives a stable ID and unique name. Captured identities leave the board but remain in move history. Castling moves both identities. Promotion changes capability only. Standard automatic game termination applies; claimable draws require a separate future interface.

Research: compare coordinates vs named locations, generic vs named entities in a factorial design. Freeze underlying positions, legal moves, engine and evaluation; counterbalance labels, control token budgets and prior associations. No measured effect is claimed.

## v0.2 lottery and controls
Each new game fixes a seed and a bijection of locations to squares. The curated confusion groups in semantic.py prohibit edge and corner adjacency, including Australia/New Zealand and Colombia/Venezuela. The lottery is constrained, not uniformly sampled over all permutations; the list is heuristic, not an exhaustive perceptual metric. The layout stays unchanged during play. Stockfish sees only canonical chess state, not country or character labels. Voice commands are parsed against the current state and must be explicitly confirmed before submission.
